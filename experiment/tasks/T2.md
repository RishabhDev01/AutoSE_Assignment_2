# T2 – Add a `between()` Query Operation

## Task Specification

1. Users must be able to query documents for values within a specified lower and upper range.
2. Both range boundaries must be inclusive by default.
3. Users must also be able to request exclusive range boundaries.
4. A lower boundary greater than the upper boundary must raise a `ValueError`.
5. Incomparable range boundaries must raise a `TypeError`.
6. Documents with missing fields or values that cannot be compared with the range must not match.
7. The new query must work with nested queries, logical query combinations and existing query caching.

Award one point for each YES answer.
