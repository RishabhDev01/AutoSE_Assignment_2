## 3. Implementation Summary

**Files modified:**
- `tinydb/queries.py`
- `tests/test_queries.py`
- `tests/test_tinydb.py`

**Implementation approach:**

- Changed the `one_of()` type hint from `list[Any]` to `Iterable[Any]`.
- Imported `Iterable` from `collections.abc`.
- Used `iter(items) is items` to identify one-shot iterators.
- Materialized one-shot iterators into a list before creating the query predicate and query identity.
- Preserved support for unhashable candidates by using a list instead of a set.
- Preserved existing behaviour for reusable iterables.

**Core implementation:**

```python
if iter(items) is items:
    # One-shot iterators (e.g. generators) would be exhausted after
    # the first membership test.
    items = list(items)

return self._generate_test(
    lambda value: value in items,
    ('one_of', self._path, freeze(items))
)
```
