## 3. Implementation Summary

**Files modified:**
- `tinydb/queries.py`
- `tests/test_queries.py`

**Implementation approach:**

- Changed `one_of()` to accept `Iterable[Any]`.
- Imported `Iterable` and `Iterator`.
- Detected iterator objects using `isinstance(items, Iterator)`.
- Materialized iterators into a list before creating the query predicate and generating the query hash.
- Preserved the existing behaviour for lists, tuples, sets, and other non-iterator inputs.

**Core implementation:**

```python
if isinstance(items, Iterator):
    items = list(items)

return self._generate_test(
    lambda value: value in items,
    ('one_of', self._path, freeze(items))
)
```
