## 2. Task Description

Fix generator exhaustion in TinyDB's `one_of()` query operation.

The implementation should:
- Support generator inputs.
- Return all matching documents when searching with a generator.
- Support repeated evaluation of the same query.
- Maintain consistent equality and hashing between equivalent generator-based and list-based queries.
- Preserve existing behaviour for other collection types.

## 3. Agent Implementation Summary

The agent identified that generators are one-shot iterators. Once consumed, subsequent membership checks operate on an exhausted generator.

The agent modified:

- `tinydb/queries.py`
- `tests/test_queries.py`
- `tests/test_tinydb.py`

### Implementation approach

- Changed the `one_of()` parameter annotation from `list[Any]` to `Iterable[Any]`.
- Imported `Iterable` and `Iterator`.
- Added a check to identify iterator inputs.
- Materialized iterator inputs into a list once.
- Reused the materialized list for membership checks and query freezing.

Conceptually:

```python
if isinstance(items, Iterator):
    items = list(items)
```

This prevents repeated generator exhaustion and allows consistent query identity and hashing.

- `test_one_of_generator_equals_list`

- `test_search_one_of_generator`
