## 2. Task Objective

Implement a `between()` query operation that supports:

- Inclusive lower and upper boundaries by default.
- Exclusive boundary behaviour.
- Invalid range validation.
- Handling of incomparable values.
- Missing fields.
- Nested queries and logical combinations.
- Existing query caching and identity mechanisms.

The agent was instructed to implement the feature and ensure that existing tests continued to pass.

## 3. Agent Implementation

The agent implemented the `between()` operation in `tinydb/queries.py`.

The implemented API uses:

`Query().field.between(lower, upper, include_lower=True, include_upper=True)`

The agent also modified test files and added 10 tests covering the new functionality.

Files modified:
- `tinydb/queries.py`
- `tests/test_queries.py`

### Observed Issues

1. The hidden evaluator expected `inclusive=False`, whereas the agent implemented separate `include_lower` and `include_upper` parameters. This caused two failures.
2. The query composition test expected `remove()` to return documents. TinyDB's existing API returns document IDs, so this assertion needs correction in the evaluator.

The acceptance result is provisional until the evaluator's `remove()` assertion is corrected and the unchanged implementation is retested.
