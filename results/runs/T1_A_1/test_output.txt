This prevents a generator from being consumed during hashing and then becoming empty during query evaluation.

## 5. Agent Approach

The agent investigated how `one_of()` handles its input values.

It identified that generators are one-shot iterators. When the query was created, the generator could be consumed while preparing the query's hash, leaving no values for subsequent evaluations.

The agent addressed this by converting iterator inputs into a list once, before constructing the query.

It retained list-based membership checking so that unhashable candidates, such as dictionaries and lists, remain supported.
