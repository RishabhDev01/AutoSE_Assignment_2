## 2. Task Description

Implement a `between()` query operation in TinyDB that supports range-based comparisons.

The operation should:
- Match values within a specified lower and upper boundary.
- Include both boundaries by default.
- Support exclusive boundaries.
- Raise `ValueError` when the lower boundary exceeds the upper boundary.
- Handle incomparable boundaries appropriately.
- Avoid matching missing fields or incomparable values.
- Work with nested queries, logical combinations, and existing caching mechanisms.

## 3. Agent Implementation

The agent implemented `between()` in `tinydb/queries.py`, following the existing query operation architecture.

The implementation supports:
- Inclusive range queries by default.
- Independent lower- and upper-bound exclusion through `include_lower` and `include_upper` flags.
- Validation of invalid or incomparable boundaries.
- Integration with nested queries and logical composition.
- Query identity and caching behaviour.

The agent modified:
- `tinydb/queries.py`
- `tests/test_queries.py`
- `tests/test_tables.py`
